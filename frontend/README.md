# 🚀 SkillSwap - AI Powered Talent Exchange Platform

SkillSwap, kullanıcıların yeteneklerini takas edebileceği modern bir platformdur. Bu proje, Google'ın en yeni yapay zeka modeli olan **Gemini 2.5 Flash** entegrasyonu ile gerçek zamanlı, akıllı bir mesajlaşma deneyimi sunar.

## ✨ Öne Çıkan Özellikler

* **Yapay Zeka Entegrasyonu:** Google Gemini API kullanılarak oluşturulmuş, bağlama duyarlı (context-aware) akıllı asistan.
* **Dinamik Zaman Algısı:** AI, gerçek zamanlı tarih ve saat bilgisiyle kullanıcıya cevap verir.
* **Modern Arayüz:** Next.js ve Tailwind CSS ile güçlendirilmiş, kullanıcı dostu ve şık tasarım.
* **Full-Stack Mimari:** Frontend ve API Route yapısı ile uçtan uca çalışan bir sistem.

## 🛠️ Kullanılan Teknolojiler

* **Framework:** Next.js 14/15
* **AI SDK:** Google Generative AI (@google/generative-ai)
* **Styling:** Tailwind CSS
* **Deployment:** Vercel & GitHub
