# 🚀 SkillSwap – AI-Powered Skill Exchange Platform

Welcome to **SkillSwap** – an innovative platform for seamless skill trading, designed and built by a Mathematical Engineering student with a passion for practical applications of algorithm theory. SkillSwap leverages advanced graph algorithms and cycle detection (notably "3-way exchanges") to match users for the most optimal and efficient talent swaps.

---

## 📚 Project Highlights

- **Mathematical Engineering Approach**: At the core of SkillSwap is an algorithmic matchmaking engine, utilizing concepts from graph theory and cycle detection. Especially, our platform supports multi-party (3-cycle) swaps—enabling scenarios where A teaches B, B teaches C, and C teaches A for skill chains impossible via direct pairs.
- **Real-Time, Intelligent Messaging**: Featuring Google Gemini 2.5 Flash integration, SkillSwap provides context-aware, AI-assisted chat—for richer, smarter, and more meaningful exchanges between users.
- **Modern, Responsive UI**: Built with Next.js and styled using Tailwind CSS, the user interface is ultra-clean, accessible, and fully responsive for all devices.
- **Real Backend Integration**: Supabase powers authentication and data management, ensuring fast, secure, and scalable full-stack experiences.
